# 서바이벌 슈터 (Survival Shooter)

탑다운 시점에서 몰려오는 적을 뚫고 최대한 오래 버티는 웹 기반 미니 게임입니다.
별도 설치나 서버 없이 `survival_shooter.html` 파일을 브라우저로 열면 바로 실행됩니다.

## 실행 방법

1. `survival_shooter.html` 파일을 더블클릭하거나 브라우저 창에 드래그해서 엽니다.
2. 시작 화면의 안내를 확인한 뒤 **게임 시작** 버튼을 누릅니다.
3. 타이틀 아래 **화면 크기** 버튼(작게/보통/크게)으로 게임 화면 크기를 바꿀 수 있습니다. 게임 중에도 언제든 조절 가능합니다.

## 조작 방법

| 플랫폼 | 이동 | 조준 / 사격 |
|---|---|---|
| PC | `WASD` 또는 방향키 | 마우스로 조준, 클릭(누르고 있으면 연사) |
| 모바일 | 화면을 드래그 | 터치 중 가장 가까운 적을 자동 조준 후 자동 발사 |

## 게임 규칙

- 화면 가장자리에서 적이 계속 스폰되어 플레이어를 향해 이동합니다.
- 생존 시간이 길어질수록 스폰 주기가 짧아지고 적 이동 속도도 올라갑니다.
- 적과 접촉하면 체력이 감소하며, 피격 직후 짧은 무적 시간이 주어집니다.
- 체력이 0이 되면 게임 오버이며, 생존 시간과 처치 수가 표시됩니다.

## 적 종류

| 타입 | 색상 | 특징 |
|---|---|---|
| 기본형 (grunt) | 빨강 | 1방에 처치, 데미지 20 |
| 고속형 (scout) | 노랑 | 이동속도 1.8배, 1방에 처치, 데미지 12 (6초 이후 등장) |
| 탱크형 (tank) | 보라 | 이동속도 0.5배, 3방을 맞혀야 처치, 데미지 30 (15초 이후 등장) |

## 강화 아이템

- 적 처치 시 9% 확률로 초록 다이아몬드 아이템이 드롭됩니다.
- 3초 안에 습득하지 못하면 사라지며(만료 0.7초 전부터 점멸), 습득하면 동시 발사 탄환이 1발 늘어납니다.
- 최대 5발까지 중첩되며, 탄환은 조준 방향을 중심으로 부채꼴로 퍼져 나갑니다.
- 화면 좌측 상단의 `AMMO` 표시로 현재 탄환 개수를 확인할 수 있습니다.

## 구현 방식

- 순수 HTML5 Canvas + Vanilla JavaScript로 작성되어 별도 라이브러리나 빌드 과정이 없습니다.
- `requestAnimationFrame` 기반 게임 루프와 델타 타임 계산으로 프레임 속도에 관계없이 동일한 속도로 동작합니다.
- 원형 충돌 판정(거리 비교)으로 총알-적, 적-플레이어, 플레이어-아이템 충돌을 처리합니다.

## 추후 확장 아이디어

- 탄환 개수 외의 다른 강화 아이템(관통, 실드 등) 추가
- 로컬 저장소를 이용한 최고 기록 저장
